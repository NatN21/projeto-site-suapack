# 🎒 SUA PACK — Site Institucional (Projeto Fictício)

Repositório de desenvolvimento do site fictício **SUA PACK**, uma marca jovem e moderna de mochilas e acessórios personalizados, com identidade inspirada na cultura pop e no estilo urbano/streetwear.

> "Monte sua vibe." — a proposta é permitir que cada pessoa expresse sua personalidade através da customização.

---

## 📌 Sobre o projeto

Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Web (Etec), com foco em planejamento de marca, identidade visual e construção de um site **mobile first** — pensado primeiro para celular, já que é assim que o público-alvo (13 a 25 anos) consome conteúdo no dia a dia.

## 🛍️ Produtos da marca

- **Mochilas personalizadas** — modelos com 3 compartimentos, design moderno e estampas customizáveis
- **Pingentes** — smiles, estrelas e elementos de cultura pop
- **Adesivos** — temáticas de música, frases e estética urbana
- **Pulseiras** — estilo miçanga/handmade
- **Bonés** — bordados exclusivos, estilo streetwear
